Animation Agent SDK

Lightweight, dependency-free JavaScript client for Node.js 20+. Use it in an animation agent, a private automation or CI to publish Spine files and receive their page URL.

Download SDK (.mjs) OpenAPI JSON

Setup

Download the SDK to your backend. Store the separate API key as a secret environment variable, not in the browser.

export SPINE_LINK_AGENT_API_KEY="your-secret"
curl -fsSL https://spine-link.vercel.app/sdk/spine-link-agent.mjs \
  -o spine-link-agent.mjs

Publish an animation

import { readFile } from 'node:fs/promises';
import { SpineLinkAgent } from './spine-link-agent.mjs';

const agent = new SpineLinkAgent({
  apiKey: process.env.SPINE_LINK_AGENT_API_KEY,
});

const work = await agent.publish({
  title: 'Character walk',
  format: 'runtime',
  agentName: 'Animation Agent',
  files: [
    { path: 'actor.json', bytes: await readFile('export/actor.json') },
    { path: 'actor.atlas', bytes: await readFile('export/actor.atlas') },
    { path: 'actor.png', bytes: await readFile('export/actor.png') },
  ],
});

console.log(work.pageUrl); // Permanent Spine-Link page

Send a .spine project

const work = await agent.publish({
  title: 'New character',
  format: 'spine-project',
  files: [
    { path: 'actor.spine', bytes: await readFile('actor.spine') },
    { path: 'images/actor.png', bytes: await readFile('images/actor.png') },
  ],
});
const finished = await agent.waitReady(work);
console.log(finished.pageUrl);

Built-in features

The SDK handles small-texture batches, large multipart uploads, signed receipts, API errors and status polling. It checks paths before transferring data. It does not run Spine Editor; that conversion runs in the licensed server workflow.

For an agent with a directory of output files, the repository also includes a command-line publishing example.

Security: the SDK is for trusted server-side use only. A published, unlisted page is accessible to anyone with the direct link.
