Animation Agent API

Connect an external animation agent to Spine-Link. Upload the files your agent produces, publish a playable page, and receive a permanent link.

REST API v1.2 · Server to server · Spine 4.3
View SDKOpenAPI JSONFull reference

Runtime export

Upload Spine JSON or SKEL, atlas, and PNG textures. Get a playable page immediately after publication.

Editor project

Upload original .spine and images/. Spine-Link queues a licensed editor conversion and reports progress.

Endpoint

POST https://spine-link.vercel.app/api/agent-animation
Authorization: Bearer <SERVER_API_KEY>
Content-Type: application/json

Four actions

All operations use the same endpoint. A separate secret key is required on the server; never embed it into browser JavaScript.

// 1. Create a publishing job
{"action":"create","title":"Robot walk","format":"runtime"}

// 2. Stage each file, or batch up to eight small files
{"action":"stage-batch","jobToken":"...","files":[
  {"name":"robot.json","contentBase64":"..."},
  {"name":"robot.atlas","contentBase64":"..."},
  {"name":"robot.png","contentBase64":"..."}
]}

// 3. Publish using signed receipts from stage responses
{"action":"complete","jobToken":"...","files":[...],
  "assemblies":[],"agentName":"2Spine","public":false}

// 4. Check status; no session token in the URL
{"action":"status","id":"agent-...","collection":"library_02"}

Response

{
  "id": "agent-...",
  "state": "ready",
  "pageUrl": "https://spine-link.vercel.app/p/agent-...",
  "animations": ["idle", "walk"]
}

Project source files can return processing until the licensed export worker finishes. Animation pages are unlisted by default, but anyone with the direct URL can view them.

Authentication and limits

Request your API key from the site administrator. The administrator must provision SPINE_LINK_AGENT_API_KEY as a server-side secret. Up to 250 files per job; batches of up to eight small assets; larger files upload in signed chunks. Upload tokens expire in 72 hours, while status-by-ID remains available.

Integration note: The endpoint is operational only after the site deployment and its API key configuration are complete. A documentation page does not imply a live authorized publishing service.
