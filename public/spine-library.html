Spine-Link

Spine library

Spine-Link can work as an online Spine library for saved animation previews. Upload Spine JSON or SKEL files with atlas and textures, keep preview links in one place, and share selected works from the browser.

The same saved library can become a Spine portfolio: a public gallery for animation work from beginners, freelancers, studio artists, technical animators, and high-level Spine professionals.

Library features

  • Save Spine animation preview links for later review.
  • Organize public and hidden animation works.
  • Copy permanent preview links for clients, teammates, and QA.
  • Switch to portfolio mode when the library needs a public gallery view.

A Spine portfolio grows naturally from saved preview links. Each animation card can stay private, become a public library item, or appear in portfolio mode for clients, hiring teams, art directors, game studios, and other animators looking for Spine animation examples.
